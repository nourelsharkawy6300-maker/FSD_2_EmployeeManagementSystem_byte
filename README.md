# Employee Management System (Task 2)

This project is an Employee Management System (CRUD) built for the Arithmatrix Virtual Internship Program (AVIP) 2026.

## Features
*   **Admin Authentication:** Secure login system required to access the management dashboard.
*   **CRUD Operations:** Full capability to Create, Read, Update, and Delete employee records.
*   **Database Integration:** Persistent data storage using MySQL.
*   **Responsive UI:** Clean and responsive interface built with Bootstrap 5.

## Tech Stack
*   Backend: PHP (PDO)
*   Database: MySQL
*   Frontend: HTML5, Bootstrap 5

## Setup Instructions
1.  Clone the repository.
2.  Create a database and run the provided SQL script to create the `employees` table.
3.  Update the database connection details in `db.php`.
4.  Run the project on a local server and log in using the admin credentials.
